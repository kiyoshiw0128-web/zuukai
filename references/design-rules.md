# 色と文字とレイアウトの決まり

`zukai_core.py` の PALETTE・FONT・MIN_PT・CONTENT がこの決まりの実体です。会社のテンプレートに合わせるときは、そこを変えます。

## 色（3色＋下地で足りる）

| 名前 | 色 | 使う所 |
|---|---|---|
| navy | #1F3A5F | 見出し、人、結論、提案の帯、選んだ物 |
| accent | #C8743A | AI、いちばん見てほしい所（**1枚に1か所**） |
| gray | #6B6B6B | 比べる相手、「いいえ」、補足、出典、根拠の札 |
| paper | #F3F1EC | 図を載せる下地 |
| line | #C8C8C8 | 罫線、使わない物 |
| mist | #E6EBF1 | 表の交互の行 |
| brown / plum | #906146 / #574D53 | 段階を色で分けるときの2番目・3番目 |

色に意味を持たせ、最後まで変えません（AIはずっとオレンジ、人はずっと紺）。

## 文字

| 場所 | 大きさ |
|---|---|
| 表紙の題 | 48pt 太字 |
| 見出し | 36pt 太字 |
| 図の中の大事なラベル、帯 | 22〜24pt 太字 |
| 図のラベル・本文 | 20pt |
| 補足、出典、札 | 18pt（これより小さくしない） |

- フォントは Noto Sans JP（Google Fonts、無料）。ない環境では PowerPoint が置き換えるので、`Deck(font="BIZ UDPゴシック")` などに変える
- 1枚のスライド上の文字は120字まで。超えたら図にするか、ナレーションへ移す
- 箱のラベルは1行に収める（`label` は収まるまで18ptまで自動で小さくする）。収まらなければ言葉を短くする

## レイアウト（16:9、13.33 x 7.5 インチ）

```
┌─┬─────────────────────────────┐
│紺│ 見出し（言い切りの1文）  y 0.5〜1.4   │
│の│ ┌───────────────────────┐ │
│帯│ │ 図（paper の下地）  y 1.5〜5.6     │ │
│  │ └───────────────────────┘ │
│  │ ┌[提案] だから、〜 ─────────────┐ │  y 5.8〜6.65（紺の帯）
│  │ 出典：〜                y 6.95       │
└─┴─────────────────────────────┘
```

- 左の紺の縦帯は全スライド共通（表紙は太く）
- 図は `CONTENT`（x 0.7, y 1.5, 幅 11.93, 高さ 4.1）の中に収める。帯を使わないスライドは y 6.5 まで使ってよい
- 余白は広めに。図の部品は枠の上下中央に置き、上に寄せて下を空けない
- 装飾（影、グラデーション、立体、クリップアート）は使わない
