# ナレーションの書き方

ナレーションは、各スライドのノートに入れる「話し手がそのまま読める台本」です。**全スライドに必ず入れます。**
スライドは目で見るもの、ナレーションは耳で聞くものです。スライドの文字を読み上げるだけにはしません。

## 型

1. **どこを見るか**: 図のどこを見ればいいかを、場所と色で言う（「左の棒が」「オレンジのマスが」）
2. **何が言えるか**: 見出しの結論を、聞き手の言葉で言う
3. **だから**: 下の帯の提案や、聞き手がすること（ないスライドもある）
4. **つなぎ**: 次のスライドへの橋渡し（「では、どうするか。」「次に、〜を見ます。」）

```
まず今の様子です。この四角ひとつが、会議の1割です。          ← どこを見るか
オレンジが、予定の時間を過ぎた会議です。10個のうち7個がオレンジですね。
つまり、だいたい7割の会議が延びています。                    ← 何が言えるか
延びることは珍しくない、だから決めることを先に書きます。      ← だから
では、どうすれば短くなるのか。次で比べてみます。              ← つなぎ
```

## 耳で聞いて分かる文にする

| 目で読む文 | 耳で聞く文 |
|---|---|
| 議題事前配布群の平均所要時間は52分 | 議題を送らなかった会議は、平均52分でした |
| A・B・Cの3案のうちBを推奨 | 案は3つあります。おすすめは真ん中のBです |
| （注：n=30） | この数字は30回の会議から出しました |

- です・ます。1文は40字前後まで。長い修飾は2文に分ける
- 略語・記号（＝、→、n=）は言葉に直す
- 数字は1文に1つ。比べるときは2つまで
- 「〜について説明します」の前置きを重ねない。すぐ中身に入る
- 聞き手に問いかけると、図を見てもらえる（「どれがいちばん多いと思いますか。」）

## 長さ

1枚100〜450字（20〜90秒。日本語は1分で約300字）。
450字を超えたら、スライドを2枚に分けるか、補足に回します。

## 読まない補足

数字の出典ページ、計算の前提、元の資料との違いなど、聞き手には話さないが話し手が知っておくべきことは、
ナレーションのあとに分けて書きます。

```
（ナレーション本文）

補足（読まない）：数字は先月の定例会議30回から。延びた＝予定の終了時刻を5分以上過ぎた会議。
```

## 表紙と最後のスライド

- 表紙: 今日の話は何で、どのくらいの時間で、最後に何を持ち帰れるかを言う
- 最後: 持ち帰る1文をもう一度言い、最初の一歩（明日いちばんにやること）で終える
