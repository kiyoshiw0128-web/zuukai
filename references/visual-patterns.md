# 伝えたいこと → 図

見出しで言いたいことの種類から、図を選びます。
選んだら「見出しと図だけで、言いたいことの7割が推測できるか」を確かめます。

| 伝えたいこと | 図 | 部品（zuukai_parts） | 絵から推測できる工夫 |
|---|---|---|---|
| 割合（何割が〜） | マスを並べる | `ratio_grid` | 1マス＝1割。色のついたマスの数で多い少ないが分かる。下に「1マス＝○○の1割」 |
| 2〜4個の数字の比較 | 縦の棒 | `bars` | 値を棒の上に大きく書く。比べたい棒だけオレンジ、ほかはグレー |
| 1つの数字の大きさ | 大きな数字 | `big_number` | 72ptの数字と、何の数字かを1行 |
| 手順・流れ | 左から右への矢印 | `flow_steps` | 箱の名前は動詞で終える（「書く」「送る」）。いちばん大事な手順だけオレンジ |
| 条件で行き先が変わる | はい／いいえの問い | `decision_flow` | 問いは「〜？」で終える。行き先の箱に絵（アイコン）を入れる |
| 変える前と後 | 左右に並べて真ん中に矢印 | `before_after` | 左はグレー、右は紺。矢印の上に「何を変えたか」 |
| 2つの軸で分ける | 2x2 | `matrix_2x2` | 軸の両端に言葉。選ぶ1マスだけオレンジ |
| いつ何をするか | 横の線と点 | `timeline` | 今いる所（または最初）だけオレンジ |
| 誰が何をするか | 役ごとのカード | `role_cards` | AIはオレンジ、人は紺のように、役の色を決めて最後まで変えない |
| やること・結論 | 番号つきの行 | `action_list` | 1行目に動詞で終わるやること、2行目に具体、右にもとにしたページ |
| 書き込む・一覧 | 表 | `table` | 見出しの行は紺、行は白と薄い色の交互。記入例を入れるなら1行だけ |
| 原因を分ける | ロジックツリー | なし（rect・arrow で組む） | 左に問題、右に原因を縦に並べる。重なり・漏れがないように |
| だんだん減る | ファネル | なし（台形を重ねる） | 上ほど幅を広く、各段に人数や件数 |
| くり返す | 循環（PDCAなど） | なし（label を円に並べ arrow でつなぐ） | 4つまで。今どこかをオレンジ |
| 階層・土台 | ピラミッド | なし（台形を重ねる） | 下が土台、上が目的 |

## アイコン（図形だけで描く）

`zuukai_core` の `icon_ai`（ロボット）、`icon_person`（人）、`icon_doc`（書類）、`icon_clock`（時計）、`icon_check`（○×）。
画像ファイルを使わないので、色を変えたり大きさを変えたりしても崩れません。
登場人物（AIと人、自社とお客さまなど）は、アイコンと色を1対1で決め、最後まで変えません。

## 図を選ぶときのよくある失敗

- 箇条書きを並べただけ → 項目の関係（順番・比較・原因）を見て、フローか表か2x2にする
- 数字を文章で書く（「約52分から31分に短縮」）→ 棒にして、文章はナレーションへ
- 色が多い → 紺・グレー・オレンジの3色で足りる。オレンジは1枚1か所
- 図の中に説明の文章 → 図のラベルは10字前後まで。説明はナレーションで話す
- 何の図か分からない → `panel(caption=...)` で左上に「何の図か」（例: 会議の平均時間（分））を書く
